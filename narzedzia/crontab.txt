# niczego nie dubluje i nie kasuje Twoich innych zadań): w katalogu repo uruchom
#   (crontab -l 2>/dev/null | grep -v 'narzedzia/automat.sh'; grep -v '^#' narzedzia/crontab.txt) \
#     | crontab -
# albo `crontab -e` i wklej linie poniżej. Sprawdzenie: `crontab -l`.
#
# Co robią (godziny w czasie systemowym serwera, który ma strefę UTC — sprawdź `timedatectl`;
# cron z Ubuntu/Debiana nie obsługuje CRON_TZ, więc po zmianie strefy serwera harmonogram się
# przesunie):
#   codziennie 06:10   DVOL BTC/ETH + manifest, commit i push manifestu
#   3. dnia 06:30      Binance top-20 za poprzedni miesiąc + manifest, commit i push (długi bieg:
#                      downloader nie jest przepisywany przyrostowo — każdy bieg pobiera całą
#                      historię od 2021-01 i nadpisuje pliki w data/ w miejscu; limit kroku 6 h.
#                      W tym oknie nie uruchamiaj rund czytających data/)
#   niedziela 18:00    raport tygodniowy raporty/tygodnie/<RRRR-Www>.md, commit i push; gdy raport
#                      ma niezatwierdzone zmiany (np. komentarz w trakcie pisania), automat odmawia
#
# Gdzie widać awarie (stdout idzie do /dev/null, więc patrz tu):
#   ~/beta_logi/cron_stderr.log          linia „[beta automat] ... BŁĄD ...” przy każdym nieudanym
#                                        biegu oraz błędy sprzed startu skryptu (np. zły Python)
#   ~/beta_logi/ostatni_status_<tryb>.txt  jedna linia: kiedy, OK albo BLAD, kod (do odczytu przez
#                                        raport tygodniowy; brak pliku = tryb nigdy nie ruszył)
#   ~/beta_logi/<RRRR-MM-DD>_<tryb>.log  pełny log (każda linia z czasem UTC, na końcu STATUS:)
# `mkdir -p` przed skryptem: bez katalogu logów przekierowanie zawiodłoby przy pierwszym biegu.
# Poczty z crona (MAILTO) nie używamy: serwer nie ma skonfigurowanej poczty.
#
# Pusha robi skrypt na bieżącą gałąź repo (musi istnieć na origin); na main/master odmawia (scalenie
# przez PR, zasada 28). Gdy repo ma stać na main, dopisz przed ścieżką skryptu AUTOMAT_PUSH_MAIN=1
# Test bez skutków ubocznych: AUTOMAT_DRY_RUN=1 /home/dantey1/beta/narzedzia/automat.sh codziennie
# (sprawdza też odczyt origin, czyli klucz SSH).

10 6 * * * /bin/mkdir -p /home/dantey1/beta_logi && /home/dantey1/beta/narzedzia/automat.sh codziennie >/dev/null 2>>/home/dantey1/beta_logi/cron_stderr.log
30 6 3 * * /bin/mkdir -p /home/dantey1/beta_logi && /home/dantey1/beta/narzedzia/automat.sh miesiac >/dev/null 2>>/home/dantey1/beta_logi/cron_stderr.log
0 18 * * 0 /bin/mkdir -p /home/dantey1/beta_logi && /home/dantey1/beta/narzedzia/automat.sh niedziela >/dev/null 2>>/home/dantey1/beta_logi/cron_stderr.log
